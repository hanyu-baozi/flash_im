# HTTP vs WebSocket 漫画分镜脚本

> 用可爱卡通角色讲解技术知识

## 角色设定

| 角色 | 形象 | 性格 | 代表 |
|---|---|---|---|
| 🐕 **小狗 HTTP** | 穿着邮递员制服，背着大包 | 勤劳但总是气喘吁吁 | HTTP 短连接 |
| 🐱 **小猫 WebSocket** | 穿着对讲机耳机，悠闲喝茶 | 淡定从容，一切尽在掌握 | WebSocket 长连接 |
| 🐰 **小兔 IM** | 戴着眼镜，拿着笔记本 | 好奇宝宝，正在创业做聊天App | IM 产品经理 |

## 附录：角色设计参考

- **外观**：棕色小狗，穿着蓝色邮递员制服
- **道具**：大邮包、电话听筒、秒表

- **口头禅**："呼...呼...又跑了一趟..."

- **外观**：白色小猫，戴着黑色耳机
- **道具**：对讲机、茶杯、闪电标志
- **表情**：悠闲淡定、从容微笑
- **口头禅**："喵~ 轻松搞定"

### 🐰 小兔 IM
- **外观**：白色小兔，戴圆框眼镜
- **道具**：笔记本、铅笔、手机
- **表情**：好奇、思考、恍然大悟
- **口头禅**："原来如此！"

## 制作建议

1. **风格**：Q版可爱风，类似《工作细胞》的风格
2. **配色**：
   - HTTP 用暖色调（橙/棕），体现忙碌感
   - WebSocket 用冷色调（蓝/青），体现稳定感
   - 背景用浅色，突出角色
3. **对话气泡**：
   - HTTP 用虚线边框（不稳定）
   - WebSocket 用实线边框（稳定连接）
4. **特效**：
   - 专线用闪光效果
   - 消息用闪电⚡符号
   - 延迟用蜗牛🐌符号
